KuraKu macOS media libraries
==========================

Local override of `media_kit_libs_macos_video` 1.1.4 (MIT).
The pinned framework archive comes from [kuraku-libmpv](https://github.com/2lineofcode/kuraku-libmpv), with audio normalization filters enabled. Downloads are checked against SHA-256.

Keep the upstream plugin registration and framework header symlinks unchanged when updating.
